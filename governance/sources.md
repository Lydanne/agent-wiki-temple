# sources

来源按 repositories、pull-requests、documents、product-walkthroughs、investigations 分类，sourceId 跨分类唯一。来源包包含 index.md，登记原地址、实际版本/完整 SHA、取得时间、覆盖范围、原件/派生件及缺口。

只归档来源不代表已更新知识。内部、敏感或大文件原件遵守实际共享授权和存储策略，不写临时签名链接或凭据。Git 代码快照只支持该版本的实现结论；视频解析需标明时间段和未覆盖部分。
