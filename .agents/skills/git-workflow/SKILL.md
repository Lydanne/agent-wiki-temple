---

先读 references/workflow.md。按目标仓库配置及当前用户请求确定 read-only/local/direct/review；目录和配置不授予身份或权限，不从其他仓库继承模式。只读请求保持只读。

先核验真实 Git 根、远端与工作区现场，再按模式执行同步、分支、适用验证、精确暂存、提交和远端交付。PR 需核对当前 head 的 CI、Review 与冲突状态；未知不能当通过。保留无关修改与失败现场，不自动 stash、强推、变基或绕过 Hook。

各仓独立交付；普通 wiki 归父仓，独立 wiki 归其自身仓库，gitlink 更新需属于当前任务。模板默认不自动合并或部署。交付明确区分本地提交、推送、PR、合并及生产验收。
