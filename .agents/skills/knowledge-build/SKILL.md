---
name: knowledge-build
description: 基于来源证据构建或更新 Feature 与共享知识，维护多视图和冲突边界。
---

先读治理的 authoring、metadata、lifecycle、llm-construction。材料未归档时先执行 knowledge-ingest 的录入流程。确定 Feature 边界并逐结论与已有正文比较；先改权威规则/领域/流程/实例/技术/数据定义，再更新关系、图和导航。排查结论按需形成 FAQ。新内容保持 draft，来源固定到真实版本，不伪造 verified。检查 source 与正文两层覆盖，执行 check 与测试；按所在仓库授权完成 Git 交付，合并和外部发布单独判断。
